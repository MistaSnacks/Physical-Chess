# Sending media to Physical Chess

This is for ACE. It explains what to send for the app, how to send it, and how we keep children safe. It goes with the sheet `media-inventory-template.csv`.

## What to send

- **Videos:** lesson clips, class clips, rodas, Batizado.
- **Photos:** classes, rodas, kicks, aús, instruments, Batizado.
- **Audio:** berimbau rhythms, songs, Portuguese words said aloud.
- **Designs:** the nine Cor designs, flyers, anything kids can print.
- **Logos:** the ABADÁ-Capoeira and ACE logos.
- **Mestre portraits:** one photo of each mestre, with their permission, and one short fact each that ACE approves.

## Formats

Send the original file, straight from the camera or phone. Please don't send screenshots or files forwarded through WhatsApp, which shrinks them.

| Kind | Best format | Notes |
|---|---|---|
| Video | MP4 or MOV | Sideways (landscape) is best. 1080p or better. |
| Photo | JPG, HEIC or PNG | The full-size original. |
| Audio | M4A, MP3 or WAV | Record in a quiet room. Leave a second of silence at each end. |
| Design | PDF, SVG or PNG | At print size. |
| Logo | SVG, or PNG with a see-through background | The logos we have now came out of a PDF with white boxes behind them. |

## How to send

1. Put the files in the shared drive folder, one folder for each kind (Videos, Photos, Audio, Designs, Logos, Portraits).
2. Add one row to the sheet for each file. If you're not sure about a column, leave it blank and we'll ask.

## The sheet, column by column

| Column | What to write |
|---|---|
| file | The file name, exactly as it is in the drive. |
| type | video, photo, audio, design or logo. |
| title | A short name for it, like "Aú from the side". |
| topic | What it shows or teaches, like "Ginga" or "Berimbau rhythms". |
| module | Movements, Music, Culture or Graduation. |
| Cor | The Cor it belongs to, or "any". |
| who appears | Who can be seen or heard, like "one adult instructor" or "children, faces visible". Describe people. Don't name children. |
| release status | Release on file, Asked and waiting, No release (do not use), or Not needed (no people). |
| credit | How to credit it, like "Video: ACE" or "Photo: [photographer]". |
| approved use | Where ACE says it may appear: App lesson, App background, Public website, Social media, Print, or Do not use yet. |

The first rows of the sheet are examples. Delete them when you start.

## Releases

- Every child who can be seen or heard needs a signed photo and video release from a parent or guardian.
- We only publish a file when its row says **Release on file**.
- If a family changes its mind, tell us and we take the file down.

## Names and children

- We never put a child's name, nickname (apelido), school or class next to their photo, video or voice.
- Please keep children's names out of file names too.
- Adults are named only if they say yes.

## What happens next

1. We bring in one video, one photo, one audio clip and one design first, so you can check how each looks in the app.
2. Once you're happy with those, we bring in the rest.
3. Videos go to YouTube as unlisted, so only people with the link can see them. Photos and audio go to the Wix media library. The originals stay in your drive.
4. Every item shows its credit in the app.
