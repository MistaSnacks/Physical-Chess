# WP10: Copy, credits and the classes page (R10.1-R10.4)

Branch `wp10-copy-credits`, based on `client-notes-v3` (67c8538). Tested in **demo mode** only (no `WIX_CLIENT_SECRET`), as v3 §2 expects until D13.

## What I built

- **R10.1 Hero.** The home H1 is now exactly "Welcome to ABADÁ Capoeira. Level up your Capoeira knowledge." The second sentence is a block `<span>` in mango, and the space before it keeps the H1's `textContent` exact. The eyebrow, `<title>`, meta description and every other "Roda Quest" label are unchanged (they wait for D8).
- **R10.2 Credits as data.**
  - Every `YOUTUBE` (10) and `WIX_VIDEOS` (12) entry in `src/data/media.js` has a `credit` field.
  - New `credit(key)` reads either table and throws on an unknown key. `yt()` still returns a plain id.
  - The "always credit SoChlo" comment is replaced by one that points to `credit()`.
  - `YouTube.astro` takes a `credit` prop in place of the hard-coded line. All four callers pass `credit(key)`: journey, lesson, batizado and graduation/media.
  - The home hero (`credit('videoProject1')`), the home "Latest from the roda" card (`credit('acb2024')`) and the lesson page's Wix-video credit (`credit(lesson.wixVideoKey)`) all read `credit()`.
- **R10.3 TV-ABADÁ.** `acb2024` now reads "Video: TV-ABADÁ Capoeira", and the footer reads "Video credits appear with each video". Every other credit is still "Video: SoChlo Productions". The Batizado media page sentence ("Videos: SoChlo Productions.") and its meta description are unchanged; that page only passes the prop.
- **R10.4 Classes page.**
  - `CONTACT.ageLine` is now a link to `/classes` at its three render sites: home hero (with an arrow icon), footer, and the contact page sub line.
  - New `/classes` uses `PublicFrame` and the public-page classes. Its sections:
    - intro and a real class photo (`classPhotoWorkshop2022`)
    - quick facts: ages shows `CONTACT.ageLine` with an "Ask ACE to confirm" tag; schedule, cost and uniform each show "Ask ACE"
    - what a class is like: four cards plus a what-to-wear note linking to /shop
    - where ACE teaches: every program from `programs.js` with its day, each tagged "To be confirmed"
    - how to join: four steps, plus phone and email
    - an inquiry form
  - The page reads only `key`, `name` and `dayOfWeek` (destructured at the top of the frontmatter). No invite code reaches the HTML or the page's JS chunk graph; I walked the chunk imports to check.
  - The form posts to `/api/contact` with `{ name, email, message }`. The route only accepts those three fields, so the child's age and chosen class are folded into `message`: `Class inquiry (from /classes)`, then age, class and the optional questions. With no API, demo mode shows "Demo: nothing was sent.", the same logic as the contact page.
  - `/classes` is in `public/sitemap.xml`, and I added a "Classes" link to the footer's Explore group.
  - The age stays 7-13 everywhere (D3). `/classes` renders `CONTACT.ageLine`, so it adds no seventh place to change.
- **Copy.** All new copy is drafted from existing `site.js` text (THE_ACE, FAQ) and sits in a `CLASSES` object in `classes.astro` with `reviewNeeded: true`. In dev, the usual "copy pending ACE review" pill shows. I invented no prices, times or locations.
- **CSS** lives in a new `src/directions/quest/wp10-classes.css`; nothing was added to `theme.css`. `Footer.astro` imports it. Pages import Footer before `theme.css`, so overrides of theme rules use two-class selectors.

- **D9 check:** the embedded `acb2024` player still shows "SoChlo Productions LLC" as the YouTube uploader under our TV-ABADÁ line (see `journey-video-*.png`). Camren is checking this internally (v3 D9).
